# DEAD RUNNER

Mobilní PWA hra inspirovaná atmosférou původního Dead Runner.

## Spuštění
GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root) → Save.

Po publikování otevři adresu GitHub Pages v Chrome na Androidu a zvol **Instalovat aplikaci** nebo **Přidat na plochu**.

## Ovládání
- Přejeď prstem doleva/doprava.
- Použij tlačítka se šipkami nebo klávesy ← →.
- Vyhýbej se stromům a překonávej vlastní rekord.

Hra ukládá nejlepší vzdálenost lokálně v zařízení a po prvním načtení funguje offline.
